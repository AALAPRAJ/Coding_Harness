# @coding-harness/frontend

This directory is the designated workspace for the frontend web application.

## Planned Implementation (Phase 5)

In accordance with `MASTER_PLAN.md` (Phase 5), this workspace will house:

- **Framework:** Next.js (App / Pages Router) with TypeScript & Tailwind CSS.
- **Task Submission Dashboard:** Form for repo URL, branch selection, and prompt.
- **Live Terminal & Execution View:** Real-time WebSockets streaming agent reasoning, file operations, and container output.
- **Interactive Diff Viewer:** Visualizing git diffs generated by the AI coding agent.

Dependencies link to `@coding-harness/shared` for unified typing across client and server.
